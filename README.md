# redix-ui-starter

A Vite SPA starter that looks and works like Pylon. The UI is installed from the `@koderi`
shadcn registry (`shared-ui`); this repo is the app around it.

```sh
npm install
npm run dev     # runs with an in-memory API mock
npm run build
npm test
```

Set `API_PROXY` to point `/api` at a real backend instead of the mock.

See `CLAUDE.md` for the layout and the rules.
